# The KC Theory — Shopify Theme

> **Clarity. Control. Confidence. Built for men who think differently.**

This is the official Shopify theme repository for [The KC Theory](https://3ag4nq-rj.myshopify.com) — a premium ADHD and men's mental health brand based in Australia. Built on Shopify Dawn (OS 2.0) with a full cinematic dark-mode brand overhaul.

---
